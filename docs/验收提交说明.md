- Mooncakes 已发布 `sssssurf/dialnumber` **0.11.0**。独立消费者从公共索引安装该版本，基本与反馈回归示例均通过。
- 验收入口：[标准对照与功能完成情况](验收材料.md)。
- 复现命令：`node scripts/acceptance.mjs`；Windows 无 C 编译器时用 `--targets js,wasm,wasm-gc`。
- 四目标各 780/780 测试通过，示例、真实演示核对、12 项基准、七类生成检查和可发布包检查通过。
- 安装证据记录依赖版本、来源和公开示例输出。[独立消费者记录](published-consumer-results.json)
- 代码与工程质量：[技术检查记录](acceptance-results.json)、CI、性质/健壮性测试及两套独立兼容性记录。
- 开源与解释材料：[许可证](../LICENSE)、[第三方来源](../THIRD_PARTY_NOTICES.md)、[开发回顾与 AI 参与说明](development-retrospective.md)。

项目交付通用电话号码解析、两级校验、地区与类型识别、四种格式化、非地理网络、号码比较、实时格式化和 RFC 3966 上下文处理。已知兼容性差异和范围边界均公开保留；不将校验通过解释为实际线路存在或可达。

本说明用于提交技术成果并申请组委会最终验收；自检结果不替代组委会正式结论。
