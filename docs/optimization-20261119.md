# 2026-11-19 交互与性能复核

当前版本 0.13.0，对比 0.12.0 / `b3eeaaa`。本轮保留全部原版参考、前缀转换和
完整往返，不以性能改动替代正确性核查。

国家/调用码按固定元数据建立索引，表顺序与主地区优先级不变。前缀语法树、捕获
组数量和格式分组在元数据行上复用；捕获内容按输入分别产生，不跨号码复用。
缓存不依赖任意用户输入，大小受固定元数据约束。

`current_output()` 复用未修改的显示，`remove_last_digit()` 删除最后一位或最初
的加号并重新分组。clear、有效输入和忽略字符分别验证。删除回归逐位比较国际、
国内、溢出、未知地区输入与新建格式器的同一前缀，不只检查最终号码。

人工号码解析在去空白前执行 250 UTF-16 单元上限。0.12.0 允许的更长补空格
输入改为返回 None，与固定原版 Google Java 9.0.17 一致。134 场景记录包含
250 单元接受及三项 TOO_LONG 拒绝，jar、适配器哈希和完整响应映射仍检查。
预算以内的错误长度仍可解析，之后分别判断 possible/valid；公开构造超长
PhoneNumber 的校验路径也保留测试。

末尾删除不等于光标编辑：任意位置插入、选择区替换、字母转换和全部特殊拨号
前缀仍不提供。六条 Java 逐键轨迹的 13 项布局差异继续公开。

相同 Windows 工具链和 JS 工作负载的优化前后结果，含全部 14 项原始统计，见
[performance-20261119.json](performance-20261119.json)。这是本机观测，预热、
负载和后端会影响数值，不是跨机器速度承诺或 CI 时间阈值。

四后端、799 个测试块、文档、示例、损坏记录检查和实际包的结果分别记录在
acceptance-results.json、published-consumer-results.json。
