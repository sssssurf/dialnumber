# dialnumber 正式验收缺陷修正（0.9.0）

历史修正记录：本页记录 2026-11-07 的修正；最新 2026-11-09 复核、实现范围和证据见 [完整复核](完整复核.md)。

日期：2026-11-07。原提交版本 0.8.1 已收到正式验收不通过通知。
本文记录反馈后的实际修正，不表示已获重审或正式通过，也不追溯声称在
10 月 31 日截止前完成。是否受理补充材料由组委会决定。

## 反馈、根因与代码修正

| 反馈 | 已确认根因 | 修正与回归 |
| --- | --- | --- |
| 国内前缀转换未实现 | 提取器仅保存 dial_transform 布尔值，丢掉实际替换字符串；解析器只删除前缀 | 保存 prefix_transform；按捕获组和贪婪/分支顺序执行替换；32 个地区全部进入执行链路 |
| 阿根廷手机解析无效、国内显示错误 | 国内的 15 需要变换成国际 NSN 的 9；显示端误把首组固定为 $1，实际格式首组是 $2 | 011 15-2345-6789 → +5491123456789 → 011 15-2345-6789；固定电话及已规范化手机号保持正确 |
| 国内往返断言跳过 | 生成器在 dial_transform 为真时不生成断言 | 删除该分支，全部地区固定/移动号码示例均执行国内输出再解析；恢复 64 个原先排除的固定/移动示例 |
| 模式重复次数溢出误接受 | v*10+d 在 Int 溢出后可变为 0 或负数，后续被解释为零次或无限次 | 累加前检查；次数、长度、嵌套和展开预算同时限制；非法模式 well_formed=false 且匹配恒为 false |
| RFC3966 参数兼容错误 | 自定义参数名按原大小写去重；m- 检查区分大小写；公开构造模型缺少字段校验；域名语法不完整 | 统一名称后去重/排序/必选检查；拒绝字段注入及保留参数重复；修复百分号等价和域名尾点/顶级标签 |

核心实现：parse.mbt、prefix_transform.mbt、format.mbt、pattern.mbt、tel_uri.mbt。
定向回归：acceptance_regression_test.mbt、examples/review。

## 可复现实例

```bash
moon run --target js cmd/main -- format "011 15-2345-6789" AR
moon run --target js examples/review
```

CLI 应输出：

```text
e164: +5491123456789
international: +54 9 11 2345-6789
national: 011 15-2345-6789
rfc3966: tel:+5491123456789
```

公开 API 示例同时检查：国内往返、`a{4294967296}` 不能匹配空串、
`M-FOO` 阻止求解、`Foo=a;foo=b` 被拒绝。预期输出随 examples/review/expected.txt 提供。

## 独立验证与来源

- 原版 Google Java libphonenumber **9.0.17**：从官方 Maven JAR 实际运行，
  SHA-256 保持固定。扩大至 **102 个场景**，其中 90 个号码流程包含全部 32 个
  转换地区、阿根廷不同区号输入、巴西运营商前缀和 NANP 本地扩展。
  每个地理号码流程同时验证 Java 国内输出在本库解析回同一号码。
- **1,872 条**前缀捕获语料：预期由独立 JavaScript RegExp.exec 计算，覆盖
  所有 32 个转换计划的匹配长度、捕获组内容及未参与组；不是用本库逻辑生成预期。
- 原有 libphonenumber-js 1.11.20/max 的 2,299 条输入与六条逐键轨迹仍保留，
  元数据来源指纹随补充字段更新；已有 15 条案例/30 个字段差异仍公开，未删除案例。
- Java 的 13 处中间空格/括号差异仍明确保留；不声称任意输入下的完整兼容。

转换字段补自原版 Google v9.0.17 XML；每条 prefix_parsing 与原表逐字核对一致，
未用旧 XML 替换其余号码规则。补充字段和原字段分别记录来源，详见
data/numbering-plans.json 的 meta.prefixTransformSource 与 data-maintenance.md。

规范依据：[RFC 3966 §3](https://www.rfc-editor.org/rfc/rfc3966.html#section-3)
及 [§5.4](https://www.rfc-editor.org/rfc/rfc3966.html#section-5.4)；
前缀变换行为对照原版 [PhoneNumberUtil.java](https://github.com/google/libphonenumber/blob/v9.0.17/java/libphonenumber/src/com/google/i18n/phonenumbers/PhoneNumberUtil.java)。
